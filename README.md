# WerWirdReich

## Projektbeschreibung
WerWirdReich ist ein Windows Forms Spiel, das von der bekannten TV-Show "Wer wird Millionär?" inspiriert wurde. Das Spiel wurde als Schulprojekt im Rahmen des Informatikunterrichts entwickelt.

## Technologien
- .NET 8.0 (Windows Forms)
- C# als Programmiersprache
- NAudio für Musik- und Soundwiedergabe
- JSON für Datenspeicherung

## Installation
Repository klonen:
``` bash
git clone https://github.com/DavidVader/WerWirdReich.git
```
- In Visual Studio öffnen
- NuGet-Pakete wiederherstellen
- Starten mit F5
